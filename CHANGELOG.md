# Changelog

Published versions of the guide and AGENTS.md, newest first. Each published version is a frozen snapshot; the rules for version numbers are in CONTRIBUTING.md. Every individual edit to the draft is also recorded in the git history and listed on the draft's edit-history page.

Everything before 1.0 is a comment draft: nothing is final.
